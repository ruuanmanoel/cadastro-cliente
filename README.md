# Sistema de Cadastro de Clientes

## Objetivo
Menu no terminal para cadastrar, listar, buscar e remover clientes.

### O que foi aprendido na prática
- Atributos, métodos e construtores
- ArrayList para guardar os objetos
- Sobrescrita do toString
- Arquitetura de camadas

### Tecnologias utilizada
- Java
- Git/Github

### Ferramentas
- Intellij IDEA

### Observação
A ideia é que os dados so sejam acessados pelo repository, como o Database está estatico qualquer classe pode acessar, mas isso é porque é apenas uma simulação do banco de dados para agilizar no desenvolvimento da regra de negocio que é o CRUD de clientes.
